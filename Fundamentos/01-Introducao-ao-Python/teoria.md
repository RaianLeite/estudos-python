# 01 — Introdução ao Python

## 1. O que é Python?

Python é uma linguagem de programação de alto nível, conhecida por sua sintaxe simples e legível. Ela permite desenvolver diferentes tipos de aplicações com menos código e uma estrutura relativamente fácil de compreender.

### Principais características
- **Alto nível:** sua sintaxe é mais próxima da linguagem humana do que a de linguagens de baixo nível.
- **Interpretada:** o código é executado pelo interpretador Python, que gerencia sua execução.
- **Tipagem dinâmica:** não é necessário declarar explicitamente o tipo de uma variável antes de atribuir um valor.
- **Multiparadigma:** permite programar utilizando diferentes estilos, como programação procedural e orientação a objetos.
- **Multiplataforma:** pode ser utilizado em Windows, Linux e macOS.
- **Grande ecossistema:** possui bibliotecas e ferramentas para diversas finalidades.

## 2. Para que Python é utilizado?

Python pode ser utilizado em várias áreas:

- **Automação:** automatizar tarefas repetitivas, arquivos e processos.
- **Desenvolvimento web:** criar aplicações e APIs.
- **Análise de dados:** processar dados e gerar relatórios.
- **Inteligência artificial:** desenvolver aplicações com modelos de IA e aprendizado de máquina.
- **Desenvolvimento de software:** criar ferramentas, sistemas e aplicações.
- **Banco de dados:** consultar, inserir, atualizar e manipular informações em bancos de dados.

## 3. Como funciona a execução de um programa?

Um programa Python normalmente é escrito em um arquivo com a extensão `.py`.

Fluxo básico:

1. O programador escreve o código.
2. O interpretador Python lê e executa o programa.
3. O programa realiza as operações definidas.
4. Os resultados são exibidos ou utilizados por outras partes do sistema.

O Python também pode ser utilizado no modo interativo, permitindo executar comandos individualmente.

## 4. O que é o interpretador Python?

O interpretador é o software responsável por executar o código Python.

Exemplo de comando no terminal:

```bash
python --version
```

Em alguns ambientes, o comando utilizado é:

```bash
python3 --version
```

Esses comandos permitem verificar a versão do Python instalada.

## 5. O que é um arquivo `.py`?

É um arquivo de texto que contém código Python.

Exemplo: `programa.py`

Conteúdo:

```python
print("Olá, mundo!")
```

Para executar o arquivo pelo terminal:

```bash
python programa.py
```

O comando pode variar conforme o sistema operacional e a instalação.

## 6. Onde Python pode ser utilizado no meu trabalho?

Exemplos de aplicações possíveis:

- Automatizar tarefas repetitivas de desenvolvimento.
- Comparar arquivos SQL e identificar diferenças.
- Verificar padrões em scripts de modelagem.
- Validar nomes de tabelas, colunas e constraints.
- Gerar relatórios de inconsistências.
- Criar ferramentas de linha de comando para organizar tarefas.

## 7. Resumo

Python é uma linguagem versátil, multiplataforma e com sintaxe legível. Seu interpretador executa o código escrito em arquivos `.py` ou no modo interativo. A linguagem pode ser utilizada para automação, desenvolvimento de software, análise de dados e integração com bancos de dados.
